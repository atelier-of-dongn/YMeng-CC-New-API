创建视频（推荐）

提交文生视频、图生视频、首尾帧或参考素材视频任务。返回 OpenAI 风格回执后，请用查询接口轮询结果。

POST /v1/video/generations
需要在请求头中携带 Authorization: Bearer <token>。示例中的请求地址已使用占位符，实际部署地址请按你的环境配置。

请求参数

modelstring模型 ID，例如 seedance-2.0。
promptstring文本提示词。素材引用名称需要与 @引用 一致。
durationinteger视频时长，单位为秒，默认 5。
ratiostring宽高比，例如 16:9、9:16、1:1。
resolutionstring分辨率，例如 720p、1080p。
imagesarray图片 URL，或包含 url、name、type 的对象。帧类型支持 first_frame 和 end_frame。
videosarray参考视频 URL，或包含 url、name 的对象。
audiosarray参考音频 URL，或包含 url、name 的对象。
materialsarray可选素材列表，每项包含 type（image/video/audio）和 url。

model 和 prompt 必填，其余参数可选。model 写在请求体中。所有素材对象的 url 必填；name 可选；materials 每项的 type 也必填。

素材与引用规则

  • 不传 name 时，按素材类型分别从 1 起自动命名为“图片N”“视频N”“音频N”，在提示词中使用 @图片1 等引用。
  • 传入 name 时，上游名称和提示词中的 @引用 均使用该名称，例如 @角色1、@场景1。
  • images[].type 仅为 first_frame 时是图生视频；first_frame + end_frame 为首尾帧视频；不传 type 时为参考图。入站也接受 last_frame，映射为尾帧。
  • 使用首帧或尾帧类型时，同时传入 audios 会被拒绝。
  • materials[].type 使用 image、video、audio，与图片的帧类型不同。命名规则相同。
不要传顶层 first_frame_url、end_frame_url、start_frame、end_frame 或 function_mode。

请求示例 · 文生视频

// 请将 API_BASE 替换为你的实际 API 服务地址
const API_BASE = "https://your-api.example.com";

fetch(`${API_BASE}/v1/video/generations`, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer your-api-key"
  },
  body: JSON.stringify({
    model: "seedance-2.0",
    prompt: "宇航员在月球行走，电影级光影，镜头缓慢推进",
    duration: 10,
    ratio: "16:9",
    resolution: "720p"
  })
});

查询视频（推荐）

查询公开视频任务状态。任务完成后，结果地址位于 result_urls。

GET /v1/videos/tasks/{task_id}

路径参数

task_idstring创建接口返回的任务 ID。

响应字段

idstring公开任务 ID。
objectstring固定为 video。
modelstring提交时的模型 ID。
statusstringqueued、in_progress、completed、failed、unknown。
progressinteger进度 0–100。
created_atinteger创建时间 Unix 秒。
completed_atinteger完成时间 Unix 秒（成功时）。
expires_atinteger过期时间 Unix 秒（若有）。
secondsstring时长（秒，字符串）。
sizestring尺寸，例如 1280x720。
errorobject失败时的错误信息，包含 message 和 code。
result_urlsarray完成后的结果地址。公开推荐字段。
公开响应不含已废弃的 url / task_id 字段。需要 TaskDto（code + data）完整字段时，使用 GET /v1/video/generations/{task_id}。

轮询示例

// 请将 API_BASE 替换为你的实际 API 服务地址
const API_BASE = "https://your-api.example.com";
const taskId = "task_xxxxxxxx";

const result = await fetch(
  `${API_BASE}/v1/videos/tasks/${taskId}`,
  { headers: { "Authorization": "Bearer your-api-key" } }
).then(response => response.json());

console.log(result.status, result.progress, result.result_urls);
